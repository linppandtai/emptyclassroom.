# 版式几何与踩坑

全部数字以 **1080×1440** 为基准。实际画布按 `s = card.w / 1080` 等比缩放，所以改尺寸不用重算，但**改比例**（比如换成 3:2）会破坏下面这些相对关系，需要重新调 `portrait.height` 与引文位置。

## 几何表（1080×1440 时的绝对值）

| 元素 | 数值 | 依据 |
|---|---|---|
| 左边距 `M` | 110 | 也是文字栏左缘 |
| 文字栏宽 | 380 | 再宽就压到立绘，再窄正文断行会碎 |
| 姓名 | 100px，步进 114，竖直起点 196，中心 x=170 | 三字块 342 高，末字底部 538 |
| 朱红细线 | x = M-4 … M-2，从名字顶 +6 到末字 -22 | 离字 10px。再远就变成两个不相干的元素 |
| 罗马字 | 19px，字距 4.2，y = 名字底 +14 | 与姓名左缘对齐（x = M+8） |
| 身份 | 21px，字距 2.0，罗马字下 40px | |
| 分隔线 | y = 身份基线下 96，x = M … M+380 | 墨 17% 透明 |
| 正文 | 22px，行距 54，起点 y = 分隔线下 152 | 三行 162 高 |
| 引文 | 22px，行距 38，起点 y=1146 | 红条宽 3px，高 = 38×行数−12 |
| 页脚 | seat 24、企划名 17、英文 10、作品名 13 | 作品名在 H−56 左侧 |
| 立绘 | 高 1100，中心 x=790，crop 0.86 | 宽 556，左缘 512，右缘 1068 |
| 渐隐 | 起点 90%，长度 10%（110px），速率 2.0 | |

自动收紧规则：若立绘左缘 < 文字栏右缘 + 16，或右缘 > 画布宽 − 6，按 3% 递减重试，最多 24 次。所以**永远不会压字**，代价是人像变小。

## 四条踩破过的问题

### 1. 深墨文字压在深色衣服上会直接消失

第一版引文横跨到人物身上，「……明天早上会很难看」的后半截被裙子吃掉，看上去像被一个矩形遮挡——其实是同色叠加。

**规则：引文宽度 = 立绘左缘 − M − 26。** 先算立绘实宽，再定文字宽度。页脚同理：作品名只能放左侧，右侧整条竖带都被人占着，灰字压上去等于没有。

### 2. 自动断行会把词拆开、把标点甩到行首

中文没有词边界，逐字断行会把「明天」拆成「…明」/「天早上…」；更难看的是句号单独占一行。

两层处理：
- 数据层：`quote` 写成数组，一行一条，断点人工定。
- 代码层：`wrap()` 做避头点，`。，、；：？！）」』】…·` 不许落行首，宁可超出一个字的宽度。

### 3. 只做 alpha 渐变会留一圈灰雾

立绘素材底部常是被硬切的（1511 处躯干一刀切）。直接 alpha 渐隐，半透明的浅色像素压在纸上会形成一条脏雾带，而且把切边暴露成一条直边。

**先沉底再渐隐**：颜色先按 `k` 乘向纸色，同时 `alpha × (1-t)` 归零。`k` 的速率（默认 2.0）比 alpha 快，像素在完全透明之前就已经是纸色，接缝消失。渐隐区压到 110px 以内，雾带就窄到读不出来。

### 4. 立绘放大就会越界出血

按「等高」摆时，画幅宽的立绘（656 宽）放大到 1250 高会宽 631，右缘 1146 — 超出画布 66px，右侧衣服被硬切，看起来像没做完。

**高度定在 1100**，宽 556，正好落在 512…1068，两边都不碰。要更大就得同时右移 `cx` 并接受右侧出血；出血在印刷里正常，在屏幕上容易读作失误。

## 多人并排的坑：高度不等于身高

立绘画幅比例差很大时（656×1511 / 498×1511 / 447×1734），同一「高度」意味着**头的大小不一样**。画幅更长的那个人（通常是腿部画得更全的）会被压成小一号，三人并排看起来矮一头。

给这个人加 `scale`（1.05~1.15 之间试），不要为了对齐去改全局高度——那会把另外两个人一起缩坏。

## 换配色时

- 深底（墨色纸）要把强调色提亮一档，朱红 `#D62C3E` 在暗处会糊，用 `#E24A52`。
- `dim` 用于拉丁小字与作品名，明度要压到纸色反差的 45% 左右，再低就看不见。
- 全卡只允许一处彩色（座位格 / 细线 / 引文条），多了就不是这套语言了。
